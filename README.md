# Go-PrintEase 标签打印管理系统

Go-PrintEase 是一款基于 Wails 框架开发的自动化标签打印工具。它结合了 BarTender 强大的打印引擎与灵活的数据管理功能，旨在为企业提供高效、精准的物料标签打印解决方案。

## 🚀 核心功能

*   **BarTender 集成**：通过 REST API 无缝对接 BarTender 引擎，支持 `.btw` 格式模板。
*   **物料数据联动**：支持导入 Excel (.xlsx) 物料清单，自动解析字段并填充至打印模板。
*   **智能模板切换**：内置 `3C` 认证标志逻辑，根据物料属性自动切换带 3C 标志的 BTW 模板。
*   **打印历史管理**：自动记录打印批次、操作时间及关键字段，实现生产溯源。
*   **本地打印机识别**：自动获取 Windows 系统已安装的打印机列表，支持 PDF 虚拟打印测试。

## 🛠️ 环境准备

在使用本系统前，请确保您的环境满足以下条件：

### 1. BarTender 配置 (必选)
*   **软件版本**：安装 BarTender 2021 或更高版本（需 Enterprise 企业版以开启 REST API 功能）。
*   **开启服务**：
    1.  打开 **BarTender Administration Console** (管理控制台)。
    2.  在“集成”选项卡中，确保 **Print Portal** 或 **Integration Builder** 服务已启动。
    3.  默认 API 地址为：`http://localhost:5159`。
*   **模板准备**：
    *   将您的 `.btw` 模板文件放入指定目录。
    *   **重要提示**：如果涉及 3C 标志，需准备两个版本，例如 `Label.btw` 和 `Label_3c.btw`。

### 2. 数据库配置
*   **MongoDB**：本系统使用 MongoDB 存储模板配置与打印记录。
*   **配置 URI**：在项目根目录（或 `internal` 目录）下找到 `.env` 文件（若没有请新建），配置如下：
    ```env
    mongodb://localhost:27017
    ```
    *程序启动后会自动创建 `printease` 数据库及相关集合。*

## 📖 如何使用

### 第一步：模板与物料管理
1.  进入 **“模板管理”** 页面。
2.  **添加模板**：
    *   输入模板名称。
    *   选择对应的 **Excel 物料清单 (.xlsx)**。系统将自动解析 Excel 的表头字段。
    *   配置 **BTW 模板路径**：指定该物料对应的 BarTender 模板文件地址。
3.  系统会自动将 Excel 内容存入数据库，作为打印时的可选数据源。

### 第二步：执行打印
1.  进入 **“标签打印”** 页面。
2.  **选择模板**：下拉选择预设的打印模板。
3.  **筛选数据**：在表单中输入关键词（如物料编码），系统将自动匹配 Excel 中的对应行数据并填充界面字段。
4.  **配置参数**：
    *   **打印机**：选择目标打印机。
    *   **批次号/数量**：设置本次打印的批次代码及打印份数。
5.  **点击打印**：系统将数据发送至 BarTender API 完成打印。

### 第三步：记录追溯
*   在 **“打印记录”** 页面，您可以按时间或批次号查询过往的打印任务，查看当时打印的具体物料参数。

## ❓ 常见问题 (FAQ)

**Q: 为什么打印机列表是空的？**
A: 系统通过 PowerShell 获取本地打印机。请确保您的操作系统为 Windows 且当前用户有执行 PowerShell 脚本的权限。

**Q: 打印时提示 "Faulted" 错误？**
A: 这通常是 BarTender REST API 返回的错误。请检查：
1. `localhost:5159` 是否可访问。
2. BTW 模板路径是否正确，且 BarTender 能够访问该文件。
3. 模板中的变量名（Named Data Sources）是否与 Excel 的表头完全匹配。

**Q: 如何进行虚拟打印测试？**
A: 在打印机下拉框中选择包含 "PDF" 字样的打印机，系统会自动开启 PDF 打印模式，将结果保存为文件。
